# Internationalisation

## Locales

`en` (default), `fr`, `de`, `tr`, `pt`, `pl`, `ja`, `it`, `es` — defined in `i18n/routing.ts` **and**
`proxy.ts` (keep both lists equal). `localePrefix: "as-needed"`: English URLs have no prefix (`/stories`),
others do (`/fr/stories`).

- `proxy.ts` — next-intl middleware for pages (skips `/api`, `/_next` and files).
- `i18n/request.ts` — loads `messages/<locale>.json` for server code; falls back to `en`.
- `app/[locale]/layout.tsx` — validates the locale and passes messages to `NextIntlClientProvider`.
- Use `Link`, `redirect`, `usePathname`, `useRouter` from `i18n/routing.ts` so links keep the locale.

## API routes and emails

API requests bypass the middleware, so `lib/i18n.ts → getRequestLocale()` picks the locale from the
`NEXT_LOCALE` cookie, then `Accept-Language`, then English. `lib/` code returns `Msg` values
(`"key"` or `msg("key", { values })`) and routes call `translateMsg()`. API texts are under the `Api`
namespace; emails under `Email`.

Zustand stores (outside React) translate with `tc()` from `lib/i18n-client.ts`, kept in sync by
`components/i18n-bridge.tsx`.

## Message files

| Path | Content |
|---|---|
| `messages/<locale>.json` | All UI strings, by namespace (`Profile`, `Wallet`, `Coins`, `Transactions`, `AuthErrors`, `Api`, `Email`, `Meta`, …). Sent to the browser. |
| `messages/legal/<locale>.json` | Legal/info pages as structured blocks (read on the server only by `components/legal-page.tsx`; missing locale → English). Translated binding documents show a notice that English prevails. |

## Adding or changing keys

1. Add the key to `messages/en.json` in the namespace the component reads (`useTranslations("X")`).
2. Add it to **all 9** locale files — a missing key shows as `Namespace.key` on the page.
3. For template keys such as ``t(`filter_${type}`)``, add a key for every value in the list or union the
   code loops over.
4. Keep ICU placeholders consistent: if the code passes `{ amount }`, every translation must contain `{amount}`.
5. Keep each file's 4-space indentation and line endings.
